# Archived ad-hoc runners

These `.py.txt` files preserve the exact bytes from the supplied original ZIP.
They are historical audit material, not supported execution entry points.

Several directly mutate frozen corpus/checkpoints, manufacture reference
attribution, relax calibration thresholds, or call providers and fixed database
targets without the guarded CLI admission. The executable paths in `scripts/`
now stop with a migration notice; no override is provided.

Use the guarded P7/P8 CLIs and the current evidence-reporting guide. Creating new
data/corpus/protocol versions is required for changed inputs; historical captures
must remain intact. `manifest.json` binds every archived original source file.
